# Лабораторная работа № 3

**Вычисление функций с использованием их разложения в степенной ряд**

**Выполнил:** Роговик Никита  
**Группа:** ИВТ-25-2б  
**Вариант:** 17

## 1. Постановка задачи

Для аргумента $x$, изменяющегося от $a$ до $b$ с шагом $(b-a)/k$, вычислить
функцию с помощью её разложения в степенной ряд в двух случаях: при заданном
$n$ и с заданной точностью $\varepsilon=0{,}0001$. Для сравнения найти значение
функции по исходной формуле.

Для варианта 17 задана функция

$$
y=\frac{e^x+e^{-x}}{2},\qquad 0{,}1\le x\le1,
$$

и её разложение

$$
S_n=1+\frac{x^2}{2!}+\frac{x^4}{4!}+\ldots+\frac{x^{2n}}{(2n)!},\qquad n=10.
$$

Для получения 10 точек с обеими границами выбрано $k=9$. Шаг равен

$$
h=\frac{1-0{,}1}{9}=0{,}1.
$$

Для каждой точки нужно вывести `SN` — сумму при заданном $n$, `SE` — сумму
с заданной точностью и `Y` — значение функции по исходной формуле.

## 2. Алгоритм программы

Члены ряда вычисляются через предыдущий член:

$$
t_0=1,\qquad t_j=t_{j-1}\frac{x^2}{(2j-1)(2j)},\quad j\ge1.
$$

Это позволяет не вычислять отдельно степени и факториалы.

1. Задать $a=0{,}1$, $b=1$, $n=10$, $k=9$, $\varepsilon=0{,}0001$ и вычислить шаг.
2. Во внешнем цикле для $i=0,\ldots,9$ определить $x=a+i h$.
3. Найти `SN`: присвоить сумме и текущему члену значение 1, затем в цикле `for`
   вычислить и прибавить члены с индексами от 1 до 10. Вместе с начальной
   единицей получится 11 слагаемых, последний — $x^{20}/20!$.
4. Найти `SE`: снова присвоить сумме и текущему члену значение 1. В цикле
   `do/while` вычислять очередной член и добавлять его к сумме, пока модуль
   члена не станет меньше $\varepsilon$. Первый член меньше заданной точности
   также включается в сумму.
5. Вычислить `Y` по формуле $(e^x+e^{-x})/2$ с помощью `Math.Exp`.
6. Вывести `X`, `SN`, `SE`, `Y` и перейти к следующей точке.

Расчёт `SN` выполняет метод `CalculateSumN`, расчёт `SE` — `CalculateSumE`.
Оба используют `CalculateNextTerm` для получения следующего члена ряда.
Метод `CalculateFunction` вычисляет исходную функцию. Вывод выполняется
методами `PrintHeader` и `PrintResult`, а `Main` задаёт параметры и организует
внешний цикл.

## 3. Текст программы

```csharp
using System;

internal class Program
{
    private static void Main()
    {
        double a = 0.1;
        double b = 1;
        int n = 10;
        int k = 9;
        double epsilon = 0.0001;
        double step = (b - a) / k;

        PrintHeader(n, epsilon);

        for (int i = 0; i <= k; i++)
        {
            double x = a + i * step;
            double sn = CalculateSumN(x, n);
            double se = CalculateSumE(x, epsilon);
            double y = CalculateFunction(x);
            PrintResult(x, sn, se, y);
        }
    }

    private static double CalculateSumN(double x, int n)
    {
        double sum = 1;
        double term = 1;

        for (int i = 1; i <= n; i++)
        {
            term = CalculateNextTerm(term, x, i);
            sum += term;
        }

        return sum;
    }

    private static double CalculateSumE(double x, double epsilon)
    {
        double sum = 1;
        double term = 1;
        int i = 1;

        do
        {
            term = CalculateNextTerm(term, x, i);
            sum += term;
            i++;
        }
        while (Math.Abs(term) >= epsilon);

        return sum;
    }

    private static double CalculateNextTerm(double term, double x, int index)
    {
        return term * x * x / ((2 * index - 1) * (2 * index));
    }

    private static double CalculateFunction(double x)
    {
        return (Math.Exp(x) + Math.Exp(-x)) / 2;
    }

    private static void PrintHeader(int n, double epsilon)
    {
        Console.WriteLine("Вариант 17");
        Console.WriteLine("Вычисление функции y = (e^x + e^(-x)) / 2");
        Console.WriteLine($"n = {n}, точность = {epsilon}");
        Console.WriteLine();
    }

    private static void PrintResult(double x, double sn, double se, double y)
    {
        Console.WriteLine($"X={x:F1} SN={sn:F12} SE={se:F12} Y={y:F12}");
    }
}
```
