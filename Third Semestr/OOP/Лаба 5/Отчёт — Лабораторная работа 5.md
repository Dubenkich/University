## 1. Анализ

Задание варианта 17:

1. Двумерный массив — удалить все строки, в которых есть хотя бы один нулевой элемент.
2. Рваный массив — добавить K строк в конец массива.
3. Строка — сдвинуть циклически влево каждое слово на количество символов,
   равное номеру этого слова в строке.

Работа с программой идёт через двухуровневое меню. В главном меню выбирается
задача, в подменю — действие: формирование, вывод, обработка.

### 1.1. Двумерный массив

**Входные данные:** количество строк и столбцов (целые от 1 до 100), элементы
массива — целые числа. Элементы вводятся с клавиатуры или задаются датчиком
случайных чисел (от 0 до 9, чтобы нули встречались).

**Выходные данные:** исходный массив, количество удалённых строк и массив после
удаления.

**Словесный алгоритм:** сначала считается, сколько строк содержат ноль. Затем
создаётся новый массив с количеством строк `rows - deletedCount`, и в него
по порядку переписываются строки без нулей.

**Классы входных данных:**

- есть строки с нулями и строки без нулей;
- ни в одной строке нет нуля;
- ноль есть во всех строках;
- массив пустой (ещё не сформирован или все строки уже удалены).

**Классы выходных данных:**

- удалена часть строк;
- удалено 0 строк, массив не изменился;
- удалены все строки, выводится «Массив пустой.»;
- сообщение об ошибке.

### 1.2. Рваный массив

**Входные данные:** количество строк (от 1 до 100), длина каждой строки
(от 1 до 100), элементы — целые числа. Для добавления вводится K (от 1 до 100),
способ заполнения новых строк и их длины.

**Выходные данные:** массив после формирования и массив после добавления строк.

**Словесный алгоритм:** создаётся новый массив ссылок длиной `старая длина + K`.
Методом `Array.Copy` в него копируются старые строки, а за ними новые.

**Классы входных данных:**

- добавление строк в пустой массив;
- добавление строк в непустой массив;
- новые строки заполняются вручную или случайно.

**Классы выходных данных:**

- массив с добавленными в конец строками;
- «Массив пустой.» при выводе пустого массива.

### 1.3. Строка

**Входные данные:** строка, введённая с клавиатуры или выбранная из массива
тестовых строк. Строка должна заканчиваться знаком `.`, `!` или `?`.

**Выходные данные:** исходная строка и результат обработки.

**Словесный алгоритм:** слова находятся регулярным выражением
`[^\s,;:.!?]+`, то есть словом считается всё между пробелами и знаками
препинания. Слова нумеруются подряд по всей строке, начиная с 1. Слово с номером
`k` сдвигается влево на `k % длина` символов: `word.Substring(shift) +
word.Substring(0, shift)`. Пробелы и знаки препинания между словами переносятся
в результат без изменений.

В примере к варианту результат для второго и третьего предложений получен
нумерацией слов внутри предложения (так звучит вариант 7). В условии варианта 17
написано «номер слова в строке», поэтому в программе слова нумеруются по всей
строке. Первое предложение в обоих случаях получается одинаковым.

**Классы входных данных:**

- обычная строка из нескольких предложений;
- строка с несколькими пробелами подряд и знаками `, ; :`;
- номер слова больше его длины;
- номер слова кратен длине слова (слово не меняется);
- строка из одного слова;
- строка пустая или без знака в конце.

**Классы выходных данных:**

- строка со сдвинутыми словами, пробелы и знаки на своих местах;
- сообщение об ошибке.

### 1.4. Исключительные ситуации

| Ситуация | Результат |
| --- | --- |
| Введены буквы вместо числа | «Ошибка: нужно ввести целое число.», ввод повторяется |
| Число не помещается в `int` | «Ошибка: слишком большое число.», ввод повторяется |
| Число вне допустимого диапазона (пункт меню, размер, K) | «Ошибка: нужно число от … до ….», ввод повторяется |
| Удаление строк из пустого двумерного массива | «Ошибка: массив пустой, удалять нечего.» |
| Вывод пустого массива | «Массив пустой.» |
| Строка пустая или не заканчивается `.`, `!`, `?` | Сообщение об ошибке, ввод повторяется |
| Обработка или вывод пустой строки | «Ошибка: строка пустая, обрабатывать нечего.» / «Строка пустая.» |

Число читается через `Convert.ToInt32`, ошибки обрабатываются через `try/catch`
(`FormatException`, `OverflowException`).

## 2. Проектирование

Программа написана в одном файле `Program.cs`, класс `Program`.

Меню:

```text
Главное меню
├── 1. Двумерный массив
│   ├── 1. Сформировать вручную
│   ├── 2. Сформировать с помощью датчика случайных чисел
│   ├── 3. Вывести массив
│   ├── 4. Удалить строки, в которых есть ноль
│   └── 0. Назад
├── 2. Рваный массив
│   ├── 1. Сформировать вручную
│   ├── 2. Сформировать с помощью датчика случайных чисел
│   ├── 3. Вывести массив
│   ├── 4. Добавить K строк в конец массива
│   └── 0. Назад
├── 3. Строка
│   ├── 1. Ввести строку с клавиатуры
│   ├── 2. Выбрать строку из тестовых
│   ├── 3. Вывести строку
│   ├── 4. Сдвинуть каждое слово влево на его номер в строке
│   └── 0. Назад
└── 0. Выход
```

Каждое меню сделано циклом `do/while` и переключателем `switch`.

### Функции

| Функция | Назначение |
| --- | --- |
| `void Main()` | Хранит массивы и строку, главное меню |
| `void WorkWithMatrix(ref int[,] matrix)` | Подменю двумерного массива |
| `void WorkWithJaggedArray(ref int[][] jaggedArray)` | Подменю рваного массива |
| `void WorkWithText(ref string text)` | Подменю строки, массив тестовых строк |
| `int[,] CreateMatrix(bool isRandom)` | Запрашивает размеры и формирует матрицу нужным способом |
| `int[,] CreateRandomMatrix(int rows, int columns)` | Заполняет матрицу случайными числами 0–9 |
| `bool HasZero(int[,] matrix, int row)` | Проверяет, есть ли ноль в строке |
| `int[,] DeleteRowsWithZero(int[,] matrix, out int deletedCount)` | Возвращает новую матрицу без строк с нулями и число удалённых строк |
| `int[][] CreateRows(int count, bool isRandom)` | Создаёт `count` строк рваного массива |
| `int[] CreateRandomRow(int length)` | Строка из случайных чисел 0–9 |
| `int[][] AddRowsToEnd(int[][] jaggedArray, int[][] newRows)` | Возвращает массив с добавленными в конец строками |
| `string ShiftWords(string text)` | Сдвигает все слова строки |
| `string ShiftWord(string word, int shift)` | Циклически сдвигает одно слово влево |
| `bool IsTextCorrect(string line)` | Проверяет, что строка заканчивается `.`, `!` или `?` |
| `int ReadInt(string text, int min = int.MinValue, int max = int.MaxValue)` | Ввод целого числа с проверкой |
| `int[,] ReadMatrix(int rows, int columns)` | Ввод элементов матрицы |
| `int[] ReadRow(int length)` | Ввод элементов строки рваного массива |
| `string ReadText()` | Ввод строки с проверкой |
| `void PrintMenu(string title, params string[] items)` | Вывод меню |
| `void PrintArray(int[,] matrix)` | Вывод двумерного массива |
| `void PrintArray(int[][] jaggedArray)` | Вывод рваного массива |
| `void PrintTestLines(string[] lines)` | Вывод списка тестовых строк |
| `void PrintText(string text, string title = "Строка: ")` | Вывод строки |

Все функции `private static`. Ввод (`Read...`) и вывод (`Print...`) вынесены
в отдельные функции, функции обработки ничего не печатают.

Использованные виды функций и параметров:

- передача по значению — большинство функций;
- `ref` — подменю получают массив или строку по ссылке, чтобы изменения
  сохранялись после выхода в главное меню;
- `out` — `DeleteRowsWithZero` возвращает через `out` количество удалённых строк;
- параметры по умолчанию — `ReadInt`, `PrintText`;
- перегрузка — две функции `PrintArray`;
- переменное число параметров — `PrintMenu(..., params string[] items)`.

Также использованы `Array.Copy`, методы класса `String` (`Substring`, `Trim`)
и регулярные выражения (`Regex.Matches`, `Regex.IsMatch`).

## 3. Текст программы

```csharp
using System;
using System.Text.RegularExpressions;

internal class Program
{
    private static void Main()
    {
        int[,] matrix = new int[0, 0];
        int[][] jaggedArray = new int[0][];
        string text = "";
        int choice;

        Console.WriteLine("Лаба 5. Вариант 17");

        do
        {
            PrintMenu("Главное меню",
                "1. Двумерный массив",
                "2. Рваный массив",
                "3. Строка",
                "0. Выход");
            choice = ReadInt("Выберите пункт: ", 0, 3);

            switch (choice)
            {
                case 1:
                    WorkWithMatrix(ref matrix);
                    break;
                case 2:
                    WorkWithJaggedArray(ref jaggedArray);
                    break;
                case 3:
                    WorkWithText(ref text);
                    break;
            }
        }
        while (choice != 0);
    }

    private static void WorkWithMatrix(ref int[,] matrix)
    {
        int choice;
        int deletedCount;

        do
        {
            PrintMenu("Двумерный массив",
                "1. Сформировать вручную",
                "2. Сформировать с помощью датчика случайных чисел",
                "3. Вывести массив",
                "4. Удалить строки, в которых есть ноль",
                "0. Назад");
            choice = ReadInt("Выберите пункт: ", 0, 4);

            switch (choice)
            {
                case 1:
                    matrix = CreateMatrix(false);
                    PrintArray(matrix);
                    break;
                case 2:
                    matrix = CreateMatrix(true);
                    PrintArray(matrix);
                    break;
                case 3:
                    PrintArray(matrix);
                    break;
                case 4:
                    if (matrix.Length == 0)
                    {
                        Console.WriteLine("Ошибка: массив пустой, удалять нечего.");
                        break;
                    }
                    matrix = DeleteRowsWithZero(matrix, out deletedCount);
                    Console.WriteLine("Удалено строк: " + deletedCount);
                    PrintArray(matrix);
                    break;
            }
        }
        while (choice != 0);
    }

    private static void WorkWithJaggedArray(ref int[][] jaggedArray)
    {
        int choice;

        do
        {
            PrintMenu("Рваный массив",
                "1. Сформировать вручную",
                "2. Сформировать с помощью датчика случайных чисел",
                "3. Вывести массив",
                "4. Добавить K строк в конец массива",
                "0. Назад");
            choice = ReadInt("Выберите пункт: ", 0, 4);

            switch (choice)
            {
                case 1:
                    jaggedArray = CreateRows(ReadInt("Количество строк: ", 1, 100), false);
                    PrintArray(jaggedArray);
                    break;
                case 2:
                    jaggedArray = CreateRows(ReadInt("Количество строк: ", 1, 100), true);
                    PrintArray(jaggedArray);
                    break;
                case 3:
                    PrintArray(jaggedArray);
                    break;
                case 4:
                    int count = ReadInt("Сколько строк добавить (K): ", 1, 100);
                    int fillChoice = ReadInt("Как заполнить новые строки (1 - вручную, 2 - случайно): ", 1, 2);
                    int[][] newRows = CreateRows(count, fillChoice == 2);
                    jaggedArray = AddRowsToEnd(jaggedArray, newRows);
                    PrintArray(jaggedArray);
                    break;
            }
        }
        while (choice != 0);
    }

    private static void WorkWithText(ref string text)
    {
        string[] testLines =
        {
            "В лесу родилась елочка. В лесу она росла. Зимой и летом стройная, зеленая была.",
            "Мама  мыла   раму!  Рама: чистая; мама рада?",
            "Привет."
        };
        int choice;

        do
        {
            PrintMenu("Строка",
                "1. Ввести строку с клавиатуры",
                "2. Выбрать строку из тестовых",
                "3. Вывести строку",
                "4. Сдвинуть каждое слово влево на его номер в строке",
                "0. Назад");
            choice = ReadInt("Выберите пункт: ", 0, 4);

            switch (choice)
            {
                case 1:
                    text = ReadText();
                    PrintText(text);
                    break;
                case 2:
                    PrintTestLines(testLines);
                    int number = ReadInt("Номер строки: ", 1, testLines.Length);
                    text = testLines[number - 1];
                    PrintText(text);
                    break;
                case 3:
                    PrintText(text);
                    break;
                case 4:
                    if (text.Length == 0)
                    {
                        Console.WriteLine("Ошибка: строка пустая, обрабатывать нечего.");
                        break;
                    }
                    PrintText(text, "Исходная строка: ");
                    PrintText(ShiftWords(text), "Результат: ");
                    break;
            }
        }
        while (choice != 0);
    }

    private static int[,] CreateMatrix(bool isRandom)
    {
        int rows = ReadInt("Количество строк: ", 1, 100);
        int columns = ReadInt("Количество столбцов: ", 1, 100);
        if (isRandom)
            return CreateRandomMatrix(rows, columns);
        return ReadMatrix(rows, columns);
    }

    private static int[,] CreateRandomMatrix(int rows, int columns)
    {
        Random random = new Random();
        int[,] matrix = new int[rows, columns];
        for (int i = 0; i < rows; i++)
        {
            for (int j = 0; j < columns; j++)
                matrix[i, j] = random.Next(0, 10);
        }
        return matrix;
    }

    private static bool HasZero(int[,] matrix, int row)
    {
        for (int j = 0; j < matrix.GetLength(1); j++)
        {
            if (matrix[row, j] == 0)
                return true;
        }
        return false;
    }

    private static int[,] DeleteRowsWithZero(int[,] matrix, out int deletedCount)
    {
        int rows = matrix.GetLength(0);
        int columns = matrix.GetLength(1);

        deletedCount = 0;
        for (int i = 0; i < rows; i++)
        {
            if (HasZero(matrix, i))
                deletedCount++;
        }

        int[,] result = new int[rows - deletedCount, columns];
        int newRow = 0;
        for (int i = 0; i < rows; i++)
        {
            if (HasZero(matrix, i))
                continue;
            for (int j = 0; j < columns; j++)
                result[newRow, j] = matrix[i, j];
            newRow++;
        }
        return result;
    }

    private static int[][] CreateRows(int count, bool isRandom)
    {
        int[][] rows = new int[count][];
        for (int i = 0; i < count; i++)
        {
            int length = ReadInt($"Длина строки {i + 1}: ", 1, 100);
            if (isRandom)
                rows[i] = CreateRandomRow(length);
            else
                rows[i] = ReadRow(length);
        }
        return rows;
    }

    private static int[] CreateRandomRow(int length)
    {
        Random random = new Random();
        int[] row = new int[length];
        for (int i = 0; i < length; i++)
            row[i] = random.Next(0, 10);
        return row;
    }

    private static int[][] AddRowsToEnd(int[][] jaggedArray, int[][] newRows)
    {
        int[][] result = new int[jaggedArray.Length + newRows.Length][];
        Array.Copy(jaggedArray, result, jaggedArray.Length);
        Array.Copy(newRows, 0, result, jaggedArray.Length, newRows.Length);
        return result;
    }

    private static string ShiftWords(string text)
    {
        MatchCollection words = Regex.Matches(text, @"[^\s,;:.!?]+");
        string result = "";
        int position = 0;
        int wordNumber = 1;

        foreach (Match word in words)
        {
            result += text.Substring(position, word.Index - position);
            result += ShiftWord(word.Value, wordNumber);
            position = word.Index + word.Length;
            wordNumber++;
        }
        result += text.Substring(position);
        return result;
    }

    private static string ShiftWord(string word, int shift)
    {
        shift = shift % word.Length;
        return word.Substring(shift) + word.Substring(0, shift);
    }

    private static bool IsTextCorrect(string line)
    {
        return Regex.IsMatch(line, @"[.!?]$");
    }

    private static int ReadInt(string text, int min = int.MinValue, int max = int.MaxValue)
    {
        int number = 0;
        bool isCorrect = false;

        do
        {
            Console.Write(text);
            try
            {
                number = Convert.ToInt32(Console.ReadLine());
                if (number < min || number > max)
                    Console.WriteLine($"Ошибка: нужно число от {min} до {max}.");
                else
                    isCorrect = true;
            }
            catch (FormatException)
            {
                Console.WriteLine("Ошибка: нужно ввести целое число.");
            }
            catch (OverflowException)
            {
                Console.WriteLine("Ошибка: слишком большое число.");
            }
        }
        while (!isCorrect);

        return number;
    }

    private static int[,] ReadMatrix(int rows, int columns)
    {
        int[,] matrix = new int[rows, columns];
        for (int i = 0; i < rows; i++)
        {
            for (int j = 0; j < columns; j++)
                matrix[i, j] = ReadInt($"Элемент [{i + 1}, {j + 1}]: ");
        }
        return matrix;
    }

    private static int[] ReadRow(int length)
    {
        int[] row = new int[length];
        for (int i = 0; i < length; i++)
            row[i] = ReadInt($"Элемент {i + 1}: ");
        return row;
    }

    private static string ReadText()
    {
        Console.WriteLine("Введите строку:");
        string? line = Console.ReadLine();
        while (line == null || !IsTextCorrect(line.Trim()))
        {
            Console.WriteLine("Ошибка: строка не должна быть пустой и должна заканчиваться знаком . ! или ?");
            line = Console.ReadLine();
        }
        return line.Trim();
    }

    private static void PrintMenu(string title, params string[] items)
    {
        Console.WriteLine();
        Console.WriteLine(title);
        foreach (string item in items)
            Console.WriteLine(item);
    }

    private static void PrintArray(int[,] matrix)
    {
        if (matrix.Length == 0)
        {
            Console.WriteLine("Массив пустой.");
            return;
        }

        for (int i = 0; i < matrix.GetLength(0); i++)
        {
            for (int j = 0; j < matrix.GetLength(1); j++)
                Console.Write(matrix[i, j] + "\t");
            Console.WriteLine();
        }
    }

    private static void PrintArray(int[][] jaggedArray)
    {
        if (jaggedArray.Length == 0)
        {
            Console.WriteLine("Массив пустой.");
            return;
        }

        for (int i = 0; i < jaggedArray.Length; i++)
        {
            foreach (int number in jaggedArray[i])
                Console.Write(number + "\t");
            Console.WriteLine();
        }
    }

    private static void PrintTestLines(string[] lines)
    {
        for (int i = 0; i < lines.Length; i++)
            Console.WriteLine($"{i + 1}. {lines[i]}");
    }

    private static void PrintText(string text, string title = "Строка: ")
    {
        if (text.Length == 0)
        {
            Console.WriteLine("Строка пустая.");
            return;
        }
        Console.WriteLine(title + text);
    }
}
```
